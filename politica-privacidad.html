Política de Privacidad

Información sobre cómo tratamos los datos personales de clientes y usuarios del área privada.

Responsable del tratamiento

El responsable del tratamiento de los datos personales es Clínica Veterinaria Vetusta, ubicada en Oviedo, Asturias. Para consultas relacionadas con privacidad o ejercicio de derechos, puede contactar mediante el email contacto@clinicaveterinariavetusta.es.

Finalidad del tratamiento

Los datos personales se tratan para gestionar el registro y acceso de usuarios al área privada, mantener la relación con los clientes, asociar mascotas a sus titulares, mostrar historiales veterinarios, gestionar documentación vinculada a las mascotas y facilitar comunicaciones relacionadas con la atención veterinaria.

También pueden utilizarse para responder consultas, gestionar citas, resolver incidencias técnicas o administrativas y mantener la seguridad de la plataforma.

Base legal

La base legal del tratamiento es la relación contractual o precontractual entre la clínica y el cliente para la prestación de servicios veterinarios, así como el consentimiento del usuario cuando crea una cuenta, facilita datos voluntariamente o sube documentación al área privada.

En algunos casos, la clínica también podrá tratar datos para cumplir obligaciones legales aplicables o por interés legítimo en mantener la seguridad, integridad y buen funcionamiento del servicio.

Datos recogidos

La clínica puede tratar las siguientes categorías de datos:

  • Nombre y apellidos del cliente.
  • Email de acceso y contacto.
  • Teléfono.
  • Datos identificativos de mascotas, como nombre, especie, raza, fecha de nacimiento e imagen.
  • Historial veterinario, vacunas, tratamientos, visitas, analíticas, notas clínicas y próximas fechas registradas por la clínica.
  • Documentos que el cliente o la clínica suban al área privada.
  • Datos técnicos necesarios para autenticación, seguridad y funcionamiento de la plataforma.

Conservación de datos

Los datos se conservarán mientras exista relación con el cliente y durante los plazos necesarios para atender obligaciones legales, administrativas o profesionales. Los datos asociados al área privada podrán mantenerse mientras la cuenta esté activa o mientras sean necesarios para la prestación y seguimiento de los servicios veterinarios.

Cuando los datos dejen de ser necesarios, se eliminarán o bloquearán conforme a los criterios legales y técnicos aplicables.

Derechos del usuario

El usuario puede solicitar el ejercicio de sus derechos de acceso, rectificación, supresión y portabilidad de sus datos personales. También podrá solicitar la limitación u oposición al tratamiento cuando proceda según la normativa aplicable.

Para ejercer estos derechos, el usuario puede escribir a contacto@clinicaveterinariavetusta.es, indicando el derecho que desea ejercer y aportando la información necesaria para verificar su identidad.

Seguridad de los datos

La clínica aplica medidas razonables de seguridad para proteger los datos personales frente a accesos no autorizados, pérdida, alteración o uso indebido. El acceso al área privada está protegido mediante autenticación y permisos diferenciados entre clientes y personal autorizado de la clínica.

Proveedor tecnológico

El área privada utiliza Supabase como proveedor tecnológico para autenticación, base de datos y almacenamiento de archivos. Supabase actúa como proveedor encargado de prestar infraestructura técnica necesaria para el funcionamiento de la plataforma, bajo las condiciones y garantías aplicables a este tipo de servicios.

Comunicación de datos

Los datos no se cederán a terceros salvo obligación legal, necesidad vinculada a la prestación del servicio veterinario o uso de proveedores tecnológicos necesarios para el funcionamiento de la plataforma.

Actualizaciones de esta política

Esta política puede actualizarse para reflejar cambios legales, técnicos u organizativos. La fecha de última actualización indicará la versión vigente.
